# Morice

Application personnelle privée d'Alan, installable sur ordinateur et Android.

## Fonctions de cette version

- espace synchronisé pour les tâches, validations, souvenirs, modules et réglages ;
- ajout de modules et de tâches depuis l'application ;
- dictée et lecture vocale depuis les navigateurs compatibles ;
- notifications Web Push réelles après consentement explicite de l'appareil ;
- installation comme application via le manifeste PWA ;
- stockage persistant par utilisateur dans D1.

## Vérification locale

```bash
pnpm install
pnpm test
```

La publication est gérée par Sites à partir de `.openai/hosting.json`.
