Le logo principal original est conservé dans l’application, les icônes et les notifications. Le compagnon au maillot 16 utilise l’atlas existant d’Alan, sans modifier son Pet OpenAI actif.

- Application : pose assise corrigée; salut au survol/focus, travail et attente utilisent les animations originales. Réduction des mouvements respectée.

- Installation sur le téléphone et rendu réel du widget : à confirmer par Alan.
- Aucun micro démarré, aucun contrôle du téléphone effectué.

L’overlay Codex reste géré par OpenAI, indépendamment du site Morice. Les nouvelles animations fournies par Alan pourront remplacer ou compléter cet atlas après validation.
